# Aufgabe

**Menu** – Eine Seite zeigt die Gerichte der Woche.

## Anforderungen

- [ ] `main.js` sucht `#menu` und prüft das Element auf `null`.
- [ ] Jedes Gericht ist ein `<li>` mit `textContent`.

## Kriterien

- **DOM:** Elemente mit `createElement`.
- **Codequalität:** `const`, englische Namen.
