# Aufgabe

**Greeting** – Das Programm fragt nach einem Namen und einer Zahl.

## Beispiellauf

```
Your name? Mia
A number? 3
Hello Mia! Twice your number is 6.
```

## Anforderungen

- [ ] Zwei `prompt()`-Aufrufe: Name, dann Zahl.
- [ ] Die Zahl wird mit `Number()` umgewandelt und verdoppelt.
- [ ] Die Ausgabe ist ein Template Literal.

## Kriterien

- **Eingabe:** Beide Antworten werden korrekt eingelesen.
- **Codequalität:** `const`, englische Namen.
