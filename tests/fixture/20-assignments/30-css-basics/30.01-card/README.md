# Aufgabe

**Card** – Eine Profilkarte.

## Anforderungen

### Struktur

- [ ] `index.html` bindet `styles.css` ein.
- [ ] Die Karte ist ein `<article class="card">` mit
  - einer `<h1>`,
  - einem Absatz.

### Design

- [ ] Die Karte hat einen Rahmen und Innenabstand.

## Kriterien

- **Struktur:** Semantische Elemente.
- **Codequalität:** Gültiges HTML.
